How to Run the App (.exe)
When you run the standalone `.exe` version for the first time, Windows SmartScreen may pop up saying "Windows protected your PC." 

Don't worry! This is completely normal for custom indie software. To play the game:
1. Click **"More info"** on the popup.
2. Click the **"Run anyway"** button that appears.
(It is the exact same code, just compacted into an exe in powershell. Have fun!)
